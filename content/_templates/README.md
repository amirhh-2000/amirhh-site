# Templates

این پوشه در هیچ Content Collectionای ایندکس نمی‌شود و فایل‌هایش روی سایت منتشر نمی‌شوند.

در Obsidian، افزونهٔ داخلی **Templates** را فعال و مسیر Template folder را روی `_templates` تنظیم کن. هنگام ساخت محتوا، قالب مناسب را در فایل جدید وارد کن و تا زمان آماده‌شدن محتوا `draft: true` را نگه دار.
